# AI Data Analyst Agent

A premium Streamlit application for automated CSV analysis, quality reporting, AI-driven insights, and exportable reporting.

## Features
- Upload and inspect CSV datasets
- Data quality and missing value analysis
- Interactive exploratory data analysis
- Statistical summaries and anomaly detection
- AI-style insights with OpenAI fallback heuristics
- Chat-style analyst assistant
- Feature engineering and ML recommendations
- Report export to CSV, HTML, and PDF

## Run locally
1. Install dependencies: `pip install -r requirements.txt`
2. Start the app: `streamlit run app.py`
3. Upload a CSV file to begin analysis

## Optional environment variables
- `OPENAI_API_KEY` to enable LLM-backed insights
